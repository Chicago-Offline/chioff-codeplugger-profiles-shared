# chioff-codeplugger-profiles-shared

**🌐 [Project site](https://chicago-offline.github.io/chioff-codeplugger-profiles-shared/)**

Shared [codeplugger](https://codeplugger.chicagooffline.com/) profiles for the
Chicago Offline community nets, plus the registered shared fleet
(`instances.yml`) and read-back-verified radio snapshots (`artifacts/`).

The site above renders every profile, the fleet, and the latest verified
snapshots. To build codeplugs from these profiles, see the
[codeplugger quick start](https://codeplugger.chicagooffline.com/#start).
